# **App Name**: Meny Back-Office

## Core Features:

- Add/Edit Customer Profiles: Allow car salespersons to create and modify customer profiles, including contact information, preferences, and purchase history.
- Log Follow-Up Activities: Enable recording of all customer interaction, such as calls, emails, and meetings, to maintain a detailed history.
- Schedule Task Reminders: Implement a reminder system for tasks like follow-up calls or appointments, ensuring timely customer engagement.
- Update Sales Funnel Status: Visually track where each customer stands in the sales process.

## Style Guidelines:

- Primary color: Dark Blue (#1A237E) to convey professionalism and trust.
- Background color: Light Gray (#F5F5F5) for a clean and modern aesthetic.
- Accent color: Orange (#FF7043) to highlight key actions and calls to action.
- Body and headline font: 'Inter' sans-serif for a modern and readable interface.
- Use simple and professional icons to represent actions and status indicators.
- Design a clean and intuitive layout that facilitates quick access to customer data and tasks.
- Incorporate subtle transitions and animations to enhance user experience and provide feedback on interactions.
